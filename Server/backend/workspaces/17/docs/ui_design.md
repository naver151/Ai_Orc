# 사용자 인터페이스 설계

## UI 요구사항

1. **사용성**: 모든 주요 기능에 빠르게 접근할 수 있어야 합니다.
2. **계산기 인터페이스**: 사용자는 직접 숫자를 입력하고 연산자를 클릭하여 연산을 수행할 수 있어야 합니다.
3. **히스토리 보기**: 이전에 수행된 계산 기록을 한눈에 볼 수 있는 인터페이스를 제공해야 합니다.

## 인터페이스 구성

### 메인 화면
1. **화면 제목**: "계산기"
2. **입력 창**: 사용자 입력을 위한 텍스트 필드.
3. **숫자 버튼**: 숫자 0~9 버튼.
4. **연산자 버튼**: +, -, *, / 버튼.
5. **기타 버튼**:
   - **= (계산 버튼)**: 현재 계산을 서버로 전송하고 결과를 반환받습니다.
   - **C (초기화 버튼)**: 현재 입력된 데이터를 초기화합니다.
6. **이전 계산 기록 버튼**: "히스토리 보기" 버튼을 통해 `/history` 엔드포인트에서 가져온 계산 기록을 표시.

### 히스토리 화면
1. **히스토리 리스트**: 이전 계산 결과와 과정을 리스트 형식으로 출력.
   - 예시 항목: `3 + 5 = 8`
2. **뒤로가기 버튼**: 메인 화면으로 돌아가는 버튼.
